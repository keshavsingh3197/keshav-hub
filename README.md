# Keshav Ecosystem Hub (`https://keshavsingh.in`)

Official main-domain hub for **keshavsingh.in**, built with **Angular 22 + `@angular/ssr` Static Site Generation (SSG)**. Every route pre-renders full static HTML for instant user loading, search engine indexing, and Google AdSense quality compliance, while interactive calculators, live YouTube catalog search, and the contact form hydrate seamlessly on the client.

## Key Sections

- **Interactive Browser Calculators (`/tools`):** YouTube & Shorts RPM / YPP Estimator, 3D Comedy & Story Short Pacing Planner (with AnimStudio Story Agent JSON export), Vikram Samvat & Sunrise-Anchored Rahu Kaal Calculator, and Microservices Latency / Capacity Planner.
- **Connected Apps Directory (`/apps` & `/apps/:slug`):** Deep capability walkthroughs and FAQs for AnimStudio AI (`studio.keshavsingh.in`), Hindu Panchang (`panchang.keshavsingh.in`), Pratiyogita (`pratiyogita.keshavsingh.in`), SocialPulse Analytics (`social.keshavsingh.in`), Engineering Content Blog (`blog.keshavsingh.in`), Ghar Ledger (`ghar.keshavsingh.in`), FamSphere Mobile App, and Developer Portfolio (`portfolio.keshavsingh.in`).
- **Creator Studio Hub (`/creators`):** Channel showcases (`@keshavsinghworld`, `@OmkarShivBhakti`, `@KESHAV-ANIM-FF`), 3D workflow documentation, and searchable multi-channel video catalog connected to `id.keshavsingh.in`.
- **Original Guides (`/guides`):** Long-form technical and creator articles covering federated SSO, FFmpeg/3D timelines, Vedic astronomy math, YouTube vs Website AdSense compliance, and Pratiyogita architecture.
- **Plans, Roadmap & Trust (`/plans`, `/roadmap`, `/interact`, `/about`, `/contact`, `/privacy-policy`, `/terms`, `/cookie-policy`, `/disclaimer`):** Ecosystem tiers, FamSphere & AdSense disclosures, encrypted Admin Contact Inbox integration, and `ads.txt`.
